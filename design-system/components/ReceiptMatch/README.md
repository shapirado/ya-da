# ReceiptMatch

Morning receipts that haven't been linked to a family yet ("קבלות לבדיקה").

Each receipt shows the payer's name or phone number as it appears on the receipt, the amount, the method and the date. If the phone number matches a parent, the dropdown pre-fills that family with a question mark and shows a teal hint. Otherwise the dropdown says **שיוך למשפחה** and lists the families that still owe money, each with the amount they're missing.
