# Button

Buttons for Ya-Da's actions, with one terracotta primary per view.

- `primary` (terracotta): the main action, which is usually **רישום תשלום** or **שמירה**.
- `whatsapp` (deep green): only for sending a reminder. Its label always includes the word WhatsApp.
- `secondary`: **סימון כשולם**, **ביטול** and other quieter actions.
- `ghost`: inline links in section headers (**לכל התשלומים**).

Sizes: `sm` (34px) in table rows, the default (40px), and `lg` (48px) for login and sheets. On mobile, the row buttons become `block` (full width) and stack vertically. In RTL the icon sits to the right of the label.
