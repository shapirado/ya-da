# MethodChip

Shows how a payment was made: ביט, פייבוקס, העברה בנקאית or מזומן.

Each method has its own accent: Bit uses teal, Paybox mustard, transfer sage and cash clay. The same colours carry into the breakdown chart. These are generic crayon icons, not the apps' logos. The second row shows the 44px selectable version used in the record-payment modal.
