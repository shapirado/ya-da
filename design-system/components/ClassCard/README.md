# ClassCard

There is one class type, חוג אומנות, taught in four weekly groups. Each card shows one group: day and time as the title, the class name below, "X/Y שילמו" and a progress ring.

When less than 60% of a class has paid, the ring turns `partial`, the card gets a partial outline, and a **מפגר בתשלום** flag appears. That makes a class that's behind easy to spot.
