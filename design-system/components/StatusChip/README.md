# StatusChip

A soft pill that shows payment status: paid, partly paid or missing.

The chip uses a `*-soft` fill with `*-ink` text and a `*-paint` dot, so status never relies on hue alone. Each chip has a word and a dot whose lightness differs. Also covers the October debt chip (`yd-debt`) and the חדש/ממשיך badges, which are gendered per child (חדשה, ממשיכה).
