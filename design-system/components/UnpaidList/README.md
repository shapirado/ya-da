# UnpaidList

The "ממתינים לתשלום" table on desktop, with one row per family that still owes money.

Columns: family (with an October debt chip when relevant), children with their group's day and time (a child who has paid gets a small ✓ chip), the amount owed (partial payments show "שולמו X מתוך Y"), the last reminder date or **לא נשלחה תזכורת** in partial-ink, then the WhatsApp and mark-as-paid buttons. Families with older debts are sorted to the top.
